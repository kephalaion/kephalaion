Kephalaion-Token prüfen

Gib deinen Kephalaion-Account und sein Account-Token ein. Die Seite prüft beides an diesem Hub und zeigt, worauf der Account Zugriff hat.

Gemeint ist das Token deines Kephalaion-Accounts – das, was dein Client (VS Code, Claude Code, …) als X-Keph-Token-<hub> schickt. Es liegt meist unter ~/.config/kephalaion/tokens/<hub>/<account>.token und beginnt mit keph_.

Nicht gemeint ist das Passwort, mit dem du dich an dieser Seite angemeldet hast, und auch nicht das Token eines Nodes.

Beginnt mit keph_. Nicht das Passwort dieser Seite.

Das Token geht nur für diese eine Prüfung an den Hub. Die Seite speichert es nicht; nach einem Neuladen fragt sie erneut.

Was die Rechte bedeuten

  • Lesen darf der Account in jeder Collection, die hier steht.
  • Schreiben (write): Neues anlegen und Eigenes ändern, löschen, umbenennen. Eigenes ist, was dein User angelegt hat.
  • Fremdes (supersede): ändern, löschen und umbenennen, was ein anderer User angelegt hat. write ist dafür nicht nötig.
  • Scopes: Unter vendor/<name>/ zählt allein der Scope vendor/<name>. write und supersede gelten dort nicht, und wer das Dokument angelegt hat, spielt keine Rolle.
  • Direkt in vendor/ schreibt niemand.

Über einen Node siehst du davon nur die Collections, die dieser Node abgleicht (kephalaion node whoami).
